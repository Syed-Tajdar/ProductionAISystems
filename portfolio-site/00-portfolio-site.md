# Project 0: Portfolio Site

One page, fast, mobile-first. This link goes on the CV, in every email signature and on LinkedIn.

## Sections

1. Hero: name, title "AI Automation Engineer", one sentence: "I build AI agents and automations that connect to real business systems and run in production." Buttons: Download CV, Email, LinkedIn, GitHub.
2. Projects: one card each for Call QA Agent, n8n Lead Automation, Bilingual RAG + MCP, Calyx case study. Each card: 2-line problem, stack tags, links (Live demo, GitHub, 2-min video).
3. Skills: grouped chips (AI and agents, Automation, Integrations, Data, Deploy).
4. Experience: short timeline (copy from CV).
5. Contact: email, WhatsApp, location and availability (for example "Based in Pakistan, open to relocate to UAE/KSA, or remote").

## Tech

- Next.js static export or plain HTML + Tailwind, deployed on Vercel.
- Own domain if possible (yourname.dev or similar), otherwise the free vercel.app URL.
- Open Graph image so the link previews nicely on WhatsApp and LinkedIn.
- No tracking scripts beyond Vercel Analytics.

## Done means

- Loads under 2 seconds on mobile, no broken links, CV PDF downloads.
